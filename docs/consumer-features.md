# Byngo OS — Consumer Features

## Voice-First Computing

Byngo OS boots directly into Chameha — the AI personality.
No lock screen. No app grid. No password prompt.
Just: "Welcome. This is Sorabbyngo."

The user expresses intent in natural language:
- "Call Mama" → Chameha dials
- "How do I treat malaria?" → Byngox health_agent responds
- "Is this medication real?" → Novela counterfeit check
- "Play music" → media intent dispatched

## Biometric Identity

No passwords. Continuous biometric verification:
- Fingerprint (primary)
- Face recognition (secondary)
- Voice print (tertiary — Chameha knows your voice)

NodeID hardware seal binds the device identity to the hardware.
If stolen, the device is cryptographically locked to its owner.

## African Languages

40+ languages via Aya 23:
- Swahili, Hausa, Yoruba, Amharic, Igbo (Tier 1 — always-on)
- Zulu, Xhosa, Shona, Twi, Wolof (via mesh upgrade)

## Android App Compatibility

Existing Android apps run via ART runtime.
No app store required — sideload APKs directly.
Apps run in a sandboxed container — cannot access NodeID or health data.

## Data Sovereignty

All personal data stays on device.
No cloud backup without explicit user consent.
No telemetry.
No advertising.
No data sale — ever.
